# Visual Lab Pro

An Interactive Engineering & STEM Virtual Laboratory built entirely in native Scilab. 

## Overview
Visual Lab Pro is a professional-grade software suite demonstrating mathematics, physics, and financial simulations through a clean, modern, and interactive GUI. 

## Modules
* **Physics Lab:** Real-time simulations of kinematic and dynamic systems.
* **Data Analytics Lab:** CSV data ingestion and statistical visualization.
* **Circuit Lab:** Interactive electrical engineering calculations.
* **Finance Lab:** Advanced business and investment calculators.

## Architecture
Built using a custom event-driven UI framework within Scilab, ensuring modularity, scalability, and strict separation of concerns.
